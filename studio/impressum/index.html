Inhalte

Texte, Gestaltung und Programmcode dieser Website stammen von Jonas Grüter. Das 3D-Modell der Büste beruht auf dem freien Grundmodell von MakeHuman (CC0). Die Website verwendet die Bibliotheken three.js und GSAP sowie die frei lizenzierten Schriften Geist und Geist Mono.

Technik

Die Website liegt bei GitHub Pages (GitHub Inc., USA). Das Kontaktformular leitet Anfragen über Web3Forms weiter. Schriften und Bibliotheken liegen auf demselben Server wie die Website, es werden keine fremden Dienste geladen.

Beispiele

Alle Beispiele auf dieser Website verwenden erfundene Namen und Daten. Ähnlichkeiten mit echten Personen oder Betrieben sind zufällig.
